# 臺灣三大重大工業氣爆地震學觀測比較研究

本專案整合臺灣近十年三大重大工業氣爆事件（**2014 年高雄地下箱涵丙烯氣爆**、**2019 年雲林麥寮台化芳香烴氣爆**、**2023 年屏東明揚科技大爆炸**）之全臺地震網觀測波形，以地球物理學、走時擬合、時頻分析（STFT）與法醫地震學（Forensic Seismology）方法，全面延伸京都大學防災研究所 Masumi Yamada 等人（2014）之成果，並產出全套 20 組專業對比圖表與互動分享網頁。

## 專案最新更新重點 (修復字型、防遮擋與名詞方法全解)

1. **圖表文字 100% 繁體中文，徹底根除方塊字 (豆腐字)**：
   - 全面註冊 Windows 原生微軟正黑體 (`msjh.ttc`)，徹底解決 Linux/Windows 跨平台字型缺字退回問題。
   - 移除不相容 Unicode 特殊符號（如 `≈`、`Δ`），全面改用繁體中文「約」、「震央距離」，確保出版級清晰度。
2. **圖例與標籤全面防遮擋優化**：
   - 重新調校全部 20 組圖表之座標軸邊界（Headroom 擴充 1.4~1.5 倍）。
   - 圖例一律配置於震波到達前的無信號靜止區（如左上方 `loc='upper left'`），徹底杜絕遮擋波形峰值、音爆到達箭頭與文字註解。
3. **新增【法醫地震學核心名詞解釋與研究方法全解】大專區**：
   - **基礎地震學**：P 波（縱波/初至壓縮波）、S 波（橫波/剪切波）、PGA（地動加速度峰值與震度階級）、三分量地震儀（Z/NS/EW）、帶通濾波（Butterworth 2.0-8.0 Hz 物理意義）。
   - **大氣與空地耦合**：超壓音爆 N-wave 跳躍機制、空地耦合效應（遠場垂直向地動放大 3~10 倍）、質點運動極化軌跡（Hodogram 判定破裂走向）、STFT 時頻譜垂直能量柱。
   - **爆轟物理與結構邊界**：地下排水箱涵波導效應、自由大氣空爆、雙重爆轟與連鎖殉爆、等效 TNT 爆炸當量。
   - **法醫地震學量化鑑識**：走時線性迴歸方程解算波速（固體波 3.52 km/s vs 音速 341.2 m/s）、累積平方能量積分（能量放大 7.3 倍測定）、雙測站互相關時間延遲法。
4. **徹底修復網頁數字符號亂碼**：
   - 引入 MathJax 3 數學排版引擎，標準渲染專業公式。
   - 清除所有 raw LaTeX 導致的 tab 縮排亂碼，全部轉譯為乾淨優雅之科學標註。
